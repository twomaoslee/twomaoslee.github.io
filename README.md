# Zi-Min Li Academic Website

Source files for [zimin.li](https://zimin.li), the bilingual academic website of Zi-Min Li at Central South University.

The site is built with Hugo Blox and deployed through GitHub Pages. English content uses the default Markdown file, while Chinese translations use the `.zh.md` suffix.

## Local preview

Use Hugo Extended 0.123.3, matching the GitHub Pages workflow:

```bash
hugo server --disableFastRender
```

Local changes are published only after they are committed and pushed to the `main` branch.
