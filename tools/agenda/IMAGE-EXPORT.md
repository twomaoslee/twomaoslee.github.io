# 分会场日程图片导出

进入具体分会场，在报告数量旁点击“导出图片”，选择日期或“张贴报告”，再点击“生成图片”。微信内长按图片保存，多张图片通过“上一张 / 下一张”逐张保存；其他浏览器同时提供下载按钮，支持文件分享的浏览器另有分享按钮。

导出当天完整日程，忽略页面搜索关键词；张贴报告单独导出，不显示时间。保留报告编号、题目、讲者、单位、时间、场次、主持人及茶歇。共享张贴报告沿用网页现有归属规则。关闭导出面板后保留原日期、筛选、滚动位置和收藏。

## 实现与维护

- 权威实现为 `source/agenda-export.js`，使用浏览器原生 Canvas 绘制，不依赖截图服务、第三方脚本、外部字体或上传接口。
- 导出模块在点击入口时才下载，约 7 KB gzip；日程复用现有缓存，需要的分会场数据未缓存时仍须先下载。数据与模块准备好后，排版、生成和预览均可离线完成。
- 每张固定 1080 像素宽，最长 3000 像素；按完整报告分页，页首重复必要信息。极长单条报告使用续页。内存不足或编码失败时以 720 像素宽重试。
- 每次只编码当前页，最多保留两页图片，关闭时释放引用。避免一次分配数十张共享张贴图片。
- 微信优先用本地 data 图片供长按保存；WebKit 离线读取 Blob 失败时回退到画布直接编码。实际手机的长按菜单由微信提供，应在发布后用手机确认。
- 不写入收藏或日程存储，不更改内部报告 ID；不包含收藏标记和优先级。
- 数据更新后，重新进入导出面板再生成，导出的是当前网页已加载的版本；已保存的图片不会自动更新。

检查：运行日程校验、构建和 `node --test tools/agenda/admin/*.test.cjs`。`export.test.cjs` 覆盖全部 34 个分会场日期/张贴分页、共享报告、完整文字、超长内容和编码失败回退。
